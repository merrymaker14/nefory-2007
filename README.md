# Неформалы 2007 — комната

Играбельный срез комнаты российского подростка-неформала осенью 2007 года.
Браузер, three.js, ходьба от первого лица.

**Открыть:** [merrymaker14.github.io/nefory-2007](https://merrymaker14.github.io/nefory-2007/)

## Управление

**Компьютер**

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | идти |
| мышь | смотреть |
| `Shift` | бегом |
| `C` | присесть |
| `E` | действие |
| `Esc` | отпустить мышь |

**Телефон и планшет**

Левая половина экрана — джойстик хода, появляется под пальцем.
Правая половина — поворот головы. Кнопка справа внизу — действие,
она загорается, когда рядом есть с чем повзаимодействовать.
Слева внизу — переключатель бега.

Взаимодействовать можно с монитором (на столе) и выключателем света (на стене у двери).

## Мобильная версия

Определяется по типу указателя и грузит облегчённый комплект:
карты освещения 2048 вместо 4096 (**16 МБ видеопамяти вместо 64 на каждую**),
уменьшенный задник, плотность пикселей ограничена 1.5, сглаживание выключено.
Угол обзора шире — на узком экране иначе тесно.

## Как это устроено

Свет **не считается в браузере вообще**. Вся сцена — один меш на 35 тысяч полигонов
и одна текстура, в которую заранее запечены и материалы, и освещение, и тени.
Считал Cycles, браузер только натягивает готовую картинку. Отсюда стабильные
60 кадров даже на слабом железе.

Два состояния света — включённый и выключенный — это две запечённые карты,
выключатель мгновенно подменяет текстуру.

Монитор — отдельная история: он рисуется на canvas каждый кадр (плеер с эквалайзером,
переписка в аське, часы), а его свечение добавляется прямо в шейдер материала комнаты,
потому что обычный источник света на запечённую сцену не подействует.

## Структура

```
src/index.html                     сцена целиком: рендер, управление, взаимодействие
assets/models/room_emo.glb         геометрия без текстур
assets/models/*_colliders.json     коробки столкновений, точки взаимодействия
assets/textures/room_lm_on.jpg     запечённый свет: люстра включена
assets/textures/room_lm_off.jpg    запечённый свет: только настольная лампа
assets/textures/backdrop_yard.png  двор за окном
```

## Локальный запуск

```bash
node serve.js        # http://localhost:8123/src/
```

Открывать двойным кликом по файлу нельзя — браузер запретит загрузку модели.

## Служебное

```bash
node shot.js         # снимки сцены через Playwright
node shot_fov.js     # сравнение углов обзора
```

Исходники Blender в репозиторий не входят — они лежат локально в `blender/`.
